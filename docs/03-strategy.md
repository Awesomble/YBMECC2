# 채널 전략 — 무엇을 만들어야 돈이 되나

리서치 기준 2026-08. 수치는 대부분 **제3자 분석 사이트 출처**(크리에이터 대시보드 집계 기반)이며
구글이 공식 공개하는 값이 아니다. **순위와 배수 감각용**으로 쓰고, 절대값을 신뢰하지 말 것.

---

> ## ⚠️ 2026-08-23 방향 전환 — 숏폼이 최우선이다
>
> 이 문서는 **"쇼츠는 유입 장치이지 수익원이 아니다"** 라고 결론지었다. **그 계산은 지금도 맞다.**
> 다만 제작 순서는 바뀌었다 — **숏폼을 1순위로 만든다.** 수익이 아니라 **속도** 때문이다:
> 피드백 루프가 즉시 돌고(Shorts Stayed to watch), 신규 유입이 강하고, 하루에 여러 편을 돌릴 수 있다.
>
> **숏폼으로 모으고 롱폼·제휴·상품으로 회수한다** — 이 문서가 계산한 그 구조 그대로다.
> 상세는 `docs/05-shorts.md`.

## 1. 단가는 3층 곱셈이다

```
최종 수익 = 국가 단가 × 니치 단가 × 포맷(롱폼/쇼츠)
```

한 층만 틀려도 자릿수가 바뀐다. 그리고 **가장 큰 함정은 세 번째 층에 있다.**

### 국가

| 국가 | 평균 CPM (₩1,400/$ 환산) |
|---|---|
| 호주 | 약 50,700원 |
| 미국 | 약 45,900원 |
| 캐나다 | 약 40,800원 |
| 뉴질랜드 | 약 39,400원 |
| **한국** | **8,000~15,000원** |

영어 콘텐츠는 이 층에서 3~5배 유리하다.

### 니치

단위: 원 (₩1,400/$ 환산)

| 니치 | CPM | 실수령 RPM |
|---|---|---|
| **B2B SaaS 튜토리얼** | **42,000~112,000** | **21,000~63,000** |
| 개인금융·투자 | 21,000~30,800 | 11,200~16,800 |
| **Make Money Online (사업·부업)** | **21,000~28,000** | 11,200~15,400 |
| **디지털 마케팅** | **16,800~25,200** | 8,400~14,000 |
| 법률 | 16,800~25,200 | — |
| 부동산 | 14,000~22,400 | — |
| AI 도구·워크플로 | 14,000~21,000 | — |
| 게임·엔터 | 1,400~11,200 | — |
| 음악 | 2,100~ | — |

전체 스프레드가 **40배**다.

### ⚠️ 포맷 — 여기가 가장 큰 함정이다

| | RPM |
|---|---|
| **쇼츠** | **$0.01 ~ 0.06** (고단가 니치 $0.15~0.25) |
| **롱폼** | **$2 ~ 15** (금융 $7~25) |

**조회당 50~250배 차이.** 실제로 계산해보면 답이 나온다.

```
하루 1편 · 편당 10만 조회 = 월 300만 조회 (매우 낙관적)

일반 니치 쇼츠   300만 × $0.03  =  $90      (12만원)
고단가 니치 쇼츠 300만 × $0.20  =  $600     (80만원)
AI 영상 제작비 (30편)           =  $135     (18만원)
─────────────────────────────────────────────
일반 니치 → 적자

vs

롱폼 금융, 월 10만 조회 (1/30)  =  $700~2,500  (95~340만원)
```

**조회수가 30분의 1인데 수익이 더 크다.**

> **쇼츠는 유입 장치이지 수익원이 아니다.**
> 쇼츠로 모으고 롱폼·자사상품으로 회수하는 구조가 아니면 숫자가 안 맞는다.

## 2. ⚠️ 정책 — 대량 생산은 제명 대상이다

유튜브가 2025-07-15 에 "반복적 콘텐츠"를 **"비진정성 콘텐츠(inauthentic content)"** 로 개명하고
2026 년에 기준을 명확히 했다.

**명시적 위반**

- 일반적인 AI 템플릿 반복
- 서로 이어지지 않는 AI 클립 짜깁기
- **대본을 그대로 읽는 TTS + 스톡 슬라이드쇼**

**제재**: 경고 → 90일 정지 → **YPP 영구 제명** (3진 아웃)

**AI 자체는 금지가 아니다.** 기준은 이것이다:

> *original value, clear creative input, meaningful editing, distinctive storytelling*

**"AI로 만들었나"가 아니라 "찍어낸 티가 나나"가 기준이다.**

→ 이 파이프라인은 **대량 생산이 아니라 제작 시간 단축**에 써야 한다. 강점도 사실 그쪽이다.
한 편을 여러 번 고쳐 뽑는 능력이지, 백 편을 찍어내는 능력이 아니다.

## 3. ⚠️ 고단가 주제의 역설

고CPM 주제 = 금융·보험·법률·의료 = 전부 **YMYL**(Your Money or Your Life).

구글이 **E-E-A-T**(경험·전문성·권위·신뢰)를 가장 엄격하게 요구하는 영역이고,
**AI 가 만든 일반론이 가장 안 먹히는 영역**이다.

> **단가가 높은 이유 자체가 "아무나 못 만들어서"다.**

즉 **"고단가 주제 × AI 대량생산"은 구조적으로 모순**이다.
단가만 보고 뛰어들면 노출도 안 되고 정책에도 걸린다.

**돌파구는 "경험(Experience)"이다.** 직접 해본 것을 기록하면 E-E-A-T 의 첫 E 를 만족한다.

## 4. 콘텐츠 사다리 — 같은 소재도 포장으로 단가가 갈린다

| 단계 | 예시 | 시청자 | 단가 |
|---|---|---|---|
| 뉴스 | "클로드 업데이트 정리" | 호기심 | 낮음 |
| 도구 소개 | "클로드로 자동화하기" | 관심자 | 중간 |
| **업무 해결** | "클로드로 인보이스 처리 자동화" | 실무자 | **높음** |
| **ROI 증명** | "이 자동화로 월 40시간 줄인 방법" | **결정권자** | **최상** |

광고 단가는 **시청자가 지갑을 열 준비가 됐는지**로 정해진다.

```
"클로드 자동화" 검색       →  개발자·얼리어답터  →  무료 도구 선호
"인보이스 처리 자동화" 검색 →  회사 실무자·사장   →  예산 있음
```

**유통기한도 다르다.**

```
뉴스형    오늘 10만 조회  →  1주일 뒤 0     →  자산 안 쌓임
튜토리얼  오늘 1천 조회   →  1~2년 지속     →  누적됨
```

자동화 파이프라인의 가치가 어느 쪽에서 나는지는 명확하다.

## 5. 수익 구조 — 애드센스는 절반도 안 된다

| 수익원 | 규모 |
|---|---|
| 애드센스 (한국 기술 채널) | CPM 8,000~15,000원 |
| **SaaS 제휴 (반복 커미션)** | **30~50%, 일부 평생** |
| **온라인 강의** | 1회 수백만원 |
| **AI 자동화 구축 대행** | **셋업 $5,000~15,000 + 월 $1,000~3,000** |

리서치 인용: **"제휴 파트너십만으로 실효 RPM 을 5배까지 올릴 수 있다"**

```
월 10만 조회 기준
애드센스만        $800 ~ 1,100      (110~150만원)
제휴 포함 (5배)   $4,000 ~ 5,500    (550~750만원)
```

### 주요 SaaS 제휴 (2026 기준)

| 프로그램 | 커미션 |
|---|---|
| Systeme.io | 60% 평생 |
| GoHighLevel | 40% 평생 + 2차 5% |
| GetResponse | 40~60% 반복 |
| Notion | 50% × 12개월 |
| HubSpot | 30% × 12개월 (쿠키 90일) |
| Webflow | 첫 구독 50% × 1년 |

업계 기준: **20% 미만 반복은 볼 가치 없음.**

⚠️ **Claude · OpenAI · Gemini · Grok 자체는 제휴 프로그램이 없는 것으로 파악된다(확인 필요).**
제휴 수익은 **모델이 아니라 주변 도구**(Zapier·Make·n8n·HubSpot·Notion 등)에서 난다.
모델은 주제이고, 돈은 도구에서 난다.

## 6. 추천 주제 — 「사업 세팅 / 실무 자동화」

**왜 이것인가**

| 축 | 평가 |
|---|---|
| **지속가능성** | **최상** — 재밌어서 계속 만든다. 채널이 죽는 1위 이유는 단가가 아니라 지침 |
| **시청자 질** | **최상** — 구매 결정권을 가진 사업주·실무자. 광고주가 원하는 그 사람 |
| **제휴 잠재력** | **최상** — 세팅 과정 전체가 제휴 상품 |
| **전환(강의·대행)** | **최상** — 시청자가 곧 잠재고객 |
| 순수 CPM | 상위권 ($12~20). 최상위는 아님 |

리서치 인용: *"열정과 수익 경로가 맞물릴 때 지속 가능한 작업이 되고, 광고·스폰서·제휴가 함께 열린다"*

**차별점**: 대부분의 채널은 **"알아본 것"** 을 정리한다. **"실제로 해본 것"** 은 3초 만에 구분된다.
그게 정책이 요구하는 *original value* 이자 경쟁자를 막는 해자다.

### 시리즈 구조 예시

사업 하나를 실제로 세팅하며 각 단계를 한 편씩:

```
1편  아이템 정하기 — 왜 이걸 골랐나
2편  사업자등록 · 법인 vs 개인
3편  도메인 · 호스팅 · 인프라
4편  결제 붙이기
5편  운영 자동화 (← 이 파이프라인이 등장하는 편)
6편  첫 매출까지
```

**연속성이 구독으로 이어진다.** 한 편 보면 다음이 궁금해진다.
그리고 시리즈가 끝나면 그대로 **강의 커리큘럼**이 된다.

각 단계마다 제휴가 붙는다: 세무 → 호스팅 → 결제(토스·스트라이프) → 자동화(Zapier·Make) → 마케팅(CRM).

## 7. 언어 선택

| | 영어 | 한국어 |
|---|---|---|
| CPM | 높음 (3~5배) | 낮음 |
| 대본·나레이션 품질 | 어려움 | **바로 됨** |
| 경쟁 | 극심 | 적음 |
| 강의·대행 전환 | 어려움 | **쉬움** |

**애드센스가 주 수익이 아니면 CPM 우위의 의미가 줄어든다.**
한국어로 시작해 신뢰를 쌓고, **같은 영상을 영어 보이스로 다시 뽑아** 확장하는 게 순서다.
파이프라인이 이미 그렇게 되어 있다 — 내레이션 JSON 만 바꾸면 된다.

## 8. 요약 체크리스트

- [ ] 쇼츠 단독 수익 모델은 접는다. 쇼츠는 **유입 전용**
- [ ] AI 는 **대량 생산이 아니라 제작 시간 단축**에 쓴다 (정책 기준이 정확히 그 선)
- [ ] 주제는 **"고단가 × 내가 실제로 하는 것"** 의 교집합
- [ ] 애드센스는 부수입. **제휴·강의·대행**을 설계에 넣는다
- [ ] 애드센스 제한 카테고리(도박·성인·의약품 등)는 아예 수익화가 막힌다. 주제 선정 시 먼저 확인
- [ ] 롱폼이 본체, 쇼츠는 미끼
