# 모션 비교 실험 — 같은 컷을 두 번 짜서 렌더로 판정한다

**왜**: 사용자가 반복해서 "모션이 약하다 · 단순하다 · 겹친다"고 지적했다 (2026-08-24 HTML 렌더 폐기
사유도 "임팩트 부족"이었다). 감각 논쟁으로 끝내지 않으려고 **같은 브리프 → 두 구현 → 수치·프레임 비교**로 만든다.

## 실측된 현재 상태 (2026-09-07)

```
enterUp     25회   아래→위 페이드. 사실상 유일한 등장 동사
punchScale  16회   튕기며 커짐
stampIn      8회   도장
exitOut      전 컷 공통, 위로 12px 페이드 — 퇴장이 하나뿐이다
clipPath/mask 0회  드러내기(롤·와이프·게이지) 모션이 없다
스태거       2 + i*3 균일 간격 — 리듬이 없다
```

**겹침의 구조적 원인**: `pipeline/motion/src/Payload.tsx` 가 `justifyContent: 'center'` 다.
콘텐츠 높이가 바뀌면 상하 경계가 같이 움직인다 — 그래서 v13 루프에서 카드가 커지자
헤드라인을 9px, 자막 밴드를 11px 침범했다 (훅은 같은 자리에서 32px 여유).
**높이 변화에 안전하지 않은 레이아웃이다.**

## 과제 — 컷 하나

**대상: `cut-06` (절정)** — "꽉 채우면 자그마치 구만 원을 아끼는 것입니다"
현재 구현: `projects/00002-온누리적립/motion/cuts/c06_10.tsx` 의 `Cut06`
비트(원음 초, 컷 로컬): `wipe 0.44` · `card 0.82` · `land 1.34` — whisper 어절 온셋 실측값이라 **바꾸지 마라**
이 컷이 대상인 이유: 카운트업·착지·임팩트가 한 컷에 모이는 절정이라 어휘 차이가 가장 잘 드러난다.

## 지켜야 할 규격 (어기면 자동 탈락)

1. **`docs/11-motion.md` 의 임팩트 예산** — 대형 임팩트는 영상 전체 36초당 4회 상한. 이 컷은 1회다
2. **세이프존** — 헤드존 344~640 · 페이로드 636~1340 · 자막 밴드 1350~1450 (`docs/09-safezone.md`).
   **어떤 프레임에서도 요소가 다른 존을 침범하면 탈락**
3. **팔레트·폰트는 `docs/12-brand.md` 확정값만** — 새 색·새 폰트 금지
4. **결정론** — 난수·시간 의존 금지. 같은 프레임은 항상 같은 픽셀이어야 한다 (`docs/02-pitfalls.md` §13)
5. **엔진에 프로젝트 값을 넣지 마라** — 영상별 값은 `projects/<p>/motion/` 안에서만
6. **비트 시각 고정** — 위 세 비트 프레임에 모션이 *끝나야* 한다 (강세 음절 = 착지점)
7. 페이지 넘김 금지 — 그라운드 고정 + 요소 교체

## 판정 — 눈이 아니라 수치

```bash
pipeline/render.sh 2 <출력파일명>          # 렌더
node pipeline/qc.mjs 2 --frames            # 수치 + 눈검사 프레임
```

| 항목 | 잰다 |
|---|---|
| 존 침범 | 헤드존·페이로드·자막 밴드 경계를 넘는 요소가 **0개** 여야 한다 |
| 모션량 | 무음 구간 프레임간 휘도차 ÷ 전체 평균. 현재 기준선 118% |
| 어휘 수 | 서로 다른 등장·퇴장·강조 동사의 개수 (현재 3개) |
| 비트 정확도 | whisper 온셋 대비 Δ ≤ 0.02초 |
| 결정론 | PNG 스틸 2회 렌더 md5 일치 (`--sequence --image-format=png`) |
