# 04. 포맷과 문안 — 학부모에게 차분하고 구체적으로

정본: 길이·구조·한국어 문안·목소리. 개정일 **2026-10-20** (ABMEN 영어 독트린을 학원 홍보용 한국어로 바꿨다).

## 1. 길이

**보여 줄 장면에 필요한 길이를 고른다.** 학원 홍보는 한 활동·한 안내를 이해시키면 끝낸다 — 사진을 더 넣어 길이를 채우지 않는다. 고정 초 수·상한은 두지 않는다(CLAUDE.md 「규격·상한 삭제」). 엔딩 카드(법정 표시·상담 안내)는 읽을 시간만큼 정지한다(05 §2-3).

## 2. 한 편의 흐름

**0초 포스터(아이가 해낸 장면) → 무엇을 하는가(활동) → 어떻게(과정·선생님·반) → 학부모에게 무엇이 남는가(지금 단계에서의 변화) → 안내(설명회·상담·레벨테스트) → 엔딩 카드.** 구간별 초 수를 고정하지 않는다.

- 첫 3초는 CLAUDE.md 최우선 규칙 그대로 — 0초 포스터는 주제 제목(예: 「7살, 영어로 발표하는 날」)·후킹(그 장면의 값 — 아이가 실제로 한 말·만든 것)·키 비주얼(가장 표정이 사는 원생 사진)을 한 장에.
- 주연은 사진 속 아이의 행동이다. 사진이 바뀔 때 「무엇이 새로 보이는가」가 있어야 한다 — 같은 크기 사진을 차례로 넘기는 슬라이드가 기본값이 되지 않게 한다(05 §3).
- 안내는 실제 날짜·방법만. 마감·잔여석은 원장이 확인한 실제 값일 때만(02 §1-3).

### 훅은 장면·말·증거를 한 묶음으로 고른다

README 「훅 선택」 표의 후보를 모든 블록에서 뽑아 비교하고 가장 강한 하나로 연다(ABMEN 2026-09-25 절대 기준 승계 — video SKILL 「최우선」).

| 학원 소재에 우선 검토할 각도 | 화면과 말의 역할 |
|---|---|
| 결과 장면 먼저 | 아이가 영어로 발표·질문·대답하는 순간을 0초에, 그 순간까지의 과정을 본문에서 |
| 하루·한 주의 흐름 | 시계·일정 띠 위로 실제 사진이 이어지며 「우리 아이의 하루」를 보여 준다 |
| 학부모의 실제 질문 | 「영어로만 수업하면 아이가 힘들지 않을까요?」 같은 상담에서 실제로 나오는 질문 → 수업 장면으로 답 |
| 행사 하이라이트 | 할로윈·스피치·졸업 발표의 가장 큰 순간 → 준비 과정 |

근거 없는 비율·순위·유행·마감·보장을 빈칸에 채우지 않는다. 가상의 학부모·원생 체험담을 지어내지 않는다.

## 3. 한국어 문안 독트린

**학부모에게 차분한 해요체로, 보이는 것을 그대로 말한다.** 화자는 아이를 잘 아는 담임 선생님처럼 구체적이고 따뜻하다. 홈쇼핑·입시 학원 광고 문체(「단 하나」「지금이 마지막」「압도적」)를 쓰지 않는다.

- 한 문장에 한 장면. 동사는 아이의 행동으로(말해요·발표해요·골라요·만들어요).
- 과정명은 공식 표기(IVY Kids·IVY Friends·IVY Master·iLearning). 대상 연령을 함께(「5~7세 IVY Kids」).
- 영어 문장은 **아이가 실제로 한 말·수업에서 실제로 쓰는 문장만** 화면에 쓰고, 처음 나올 때 짧은 뜻을 붙인다.
- 🔴 금지(코드가 막는다 — 02 §1): 선행·학년 앞당김, 유치원(유사) 명칭, 결과 보장. 근거가 있을 때만: 최상급·순위·실적·후기·모집 긴급성.
- 아이를 비교·평가하지 않는다(「다른 아이보다」「뒤처지면」). 불안을 파는 말(「지금 안 하면 늦어요」)은 쓰지 않는다 — 공포 소구는 기존 금지 표현(`platforms.json` `banned_phrases`)에도 걸린다.
- 원생 실명·학교명을 말하지 않는다.

| 피할 표현 | 권장 방향 |
|---|---|
| 「대치동 1위 영어학원」 | 「대치에서 5~7세 아이들이 영어로 하루를 보내는 곳」 |
| 「초등 전에 중등 문법까지 끝내요」 | 「지금 배우는 말을 문장으로 발표해요」 |
| 「영어유치원 과정」 | 「5~7세 IVY Kids 과정」 |
| 「성적 향상 보장」 | 「한 학기 동안 아이가 쓴 글이 이렇게 길어졌어요」 (실제 원생 작품·동의가 있을 때) |
| 「마감 임박! 서두르세요」 | 「11월 설명회는 ○일 ○시예요」 (원장 확인 날짜) |

## 4. 음성과 자막

### 캐스팅 — ② 대본 첫 초안 전에 정한다

**기본은 성인 내레이터 한 목소리**다. 학부모 대상 안내는 한 사람이 차분하게 말하는 편이 정보가 잘 들린다. 2인 대화는 사용자가 그 편에 요청할 때만 쓰고, **실존 인물(원장·선생님·학부모)인 척하는 AI 목소리·가짜 후기 대화는 쓰지 않는다**(02 §2·§1-3).

| 캐스트 | 언제 | 화자 키 → voice_id (Typecast, `ssfm-v30`) |
|---|---|---|
| **내레이터 한 명** (기본) | 사용자가 따로 말하지 않으면 | `narrator` → **Yeonhwa** `tc_600697fd8a8ea9b977284703` (2026-10-20 사용자 선택 · 00001 · 오디션 원음 `resources/voices/audition/yeonhwa-ko.wav`, 설정 ssfm-v30·normal·seed 1970·−14 LUFS). 3인칭 내레이터로만 — 학부모·원장 1인칭으로 쓰지 않는다 |
| 원생의 실제 목소리 | 동의받은 영상 클립의 현장음을 쓸 때 | 합성하지 않는다 — 클립 원음. 동의 장부 범위에 「목소리」 포함 여부를 적는다 |
| AI 아이 목소리 | 쓰지 않는다 | 원생처럼 들리는 합성 아이 목소리는 실제 원생으로 오인된다 |

- 🔴 **유료 합성 전 확인:** 타입캐스트 이용정책은 지점·사업자마다 따로 가입하라고 적는다(02 §1-8). 어느 명의 구독으로 만들지 사용자 확인 전에는 `tts.mjs`를 typecast로 돌리지 않는다. 길이 점검은 무료 `node pipeline/tts.mjs <p> --measure`(macOS `say` Yuna).
- 화자 키와 voice_id는 이 표를 정본으로 `cuts.json` `voice.speakers`에 옮기고 README `캐스팅:` 한 줄에 적는다.
- 원음 1.0배 → 조립 단일 atempo 1.20의 시간 계약은 ABMEN과 같다. 한국어에서 1.20배가 빠르게 들리면 그 편 README에 실측과 함께 적고 사용자와 정한다(임의 재가속 금지).

### 자막

- 한국어 자막은 의미 단위로 끊고 어절 중간에서 줄을 바꾸지 않는다(루트 `word-break:keep-all`). 금액·날짜·단위를 나누지 않는다.
- 사진 위 자막: 흰 글자 + Plum Ink 8px 외곽선, 강조 단어 Gold(05 §2). 자막 뒤 띠를 깔지 않는다.
- 영어 발화 자막은 원문을 크게, 뜻은 한 줄 작게.
- 핵심 발화의 자막·화면·소리 강조는 [채널05 §3-1](05-brand-pipeline.md)을 그대로 적용한다. 무음으로 뜻이 통하는지 실제 화면에서 본다.

## 5. 판단할 것

첫 프레임에서 「어떤 아이가 무엇을 하는 장면인지」 알아보는가, 학부모가 다음에 할 행동(상담·설명회)을 아는가, 화면의 주장이 사진의 사실과 맞는가, 법정 표시가 읽히는가를 본다. 사진 수·모션 수·색 비율만으로 반려하지 않는다.
