# 05. 화면과 제작 준비 — 원생 사진이 주연인 홍보 영상

정본: YBMECC 화면 방향·브랜드·제작 품질. 개정일 **2026-10-20** (ABMEN 05에서 이식 — 제작 품질 원리 §3-1은 승계, 디자인·사진 규칙은 새로 정함).

## 1. 컨셉과 적용 범위

**원생의 실제 수업·행사 사진이 화면의 주연이고, 2D 그래픽은 사진이 보여 주는 활동·순서·일정을 읽게 하는 층이다.** 사진을 풀화면으로 크게 쓰고(확대·이동·마스크로 시선을 옮긴다), 브랜드 색면·짧은 라벨·포인터·일정 띠를 그 위에 얹는다. 정보만 있는 화면(과정표·일정)은 Ivory 무대 위 2D 도식으로 만든다.

YBM ECC 공식 마크의 버건디·오렌지가 브랜드 색이다. 본사 홈페이지·인쇄물의 레이아웃·사진·일러스트를 복제하지 않는다 — 색과 마크만 공유하고 영상 문법은 이 문서가 정한다.

### 2-1. 로고 — YBM ECC 대치점 (2026-10-20)

원본 `resources/brand/ybmecc-daechi.html`(공식 마크 `ybmecc-mark.svg` 무변형 + Pretendard Black 「대치점」)을 Chrome 헤드리스로 투명 PNG 렌더. 4종:

| `ybmecc-daechi-plate.png` | 흰 캡슐 안 마크 │ 버건디 「대치점」 | 탭형이 무거울 때의 대안 |
| `ybmecc-daechi-clear.png` | 판 없이 마크 │ 「대치점」 | Ivory·흰 바탕 카드·엔딩 카드 |
| `ybmecc-daechi-stack.png` | 흰 판 위 마크, 아래 버건디 띠 「대치점」 | 정사각 자리(카드 모서리·프로필 보조) |

- **마크는 고치지 않는다** — 재채색·늘이기·그림자 효과·잘라 쓰기 금지. 어두운 사진 위에서는 흰 판이 있는 판을 쓴다.

- 가맹본부 CI 가이드는 확인하지 못했다(02 §1-8) — 받으면 이 절을 고친다.
- 다시 뽑기: `resources/brand/SOURCES.md`.

## 3. 화면·모션·소리

- **사진은 움직임으로 읽힌다:** 사진 속 아이의 시선·손끝이 가리키는 쪽으로 카메라를 옮기고(확대·이동), 다음 사진은 그 방향에서 이어 받는다(매치 컷·마스크 와이프). 같은 크기 사진을 일정 간격으로 넘기는 슬라이드·켄번스만 반복하지 않는다.
- **한 사진 한 가지 새 정보:** 사진이 바뀌면 활동·순서·결과 중 하나가 새로 보여야 한다. 같은 뜻의 사진을 여러 장 넣지 않는다.
- **2D 층의 역할:** 일정 띠(시계·요일), 과정 칩(IVY Kids 5~7세), 아이 발화 말풍선(실제로 한 말만), 포인터·밑줄(Orange). 사진의 얼굴을 덮지 않는다.
- **식별 정보 가리기:** 이름표·교복 학교명·셔틀 번호가 보이면 크롭·흐림으로 가린다(02 §1-4). 흐림은 셰이더 층(`docs/14-hyperframes.md` §16) 또는 CSS `filter:blur` 마스크.
- **사진 품질:** 확대 배율에서 표시 픽셀 < 소스 픽셀(photo-intake는 긴 변 2400px까지 보존). 흔들림·역광 사진은 키 비주얼로 쓰지 않는다.
- **소리:** 밝고 차분한 CC0 BGM, 장면 전환·강조에 효과음. 원생 현장음(동의 범위 안)은 그 순간 BGM을 낮춘다.

## 3-1. 제작 품질과 발화별 강조 연출 — 필수 적용 (ABMEN 2026-09-22 승계)

**핵심 발화와 맞춘 자막 임팩트·화면 연출·소리를 결합한다. 모든 영상의 기획·구현·검수에 필수 적용한다.** 팔레트와 로고만 맞거나 기술 검사만 통과한 영상을 이 기준 충족으로 보고하지 않는다. 첫 3초는 이 절보다 먼저 video SKILL 맨 앞 「최우선 — 첫 1·2·3초」를 적용한다.

| 요소 | 설계·구현 기준 |
|---|---|
| 자막 효과·임팩트 | 의미 단위 자막에서 핵심 단어·구절의 크기·굵기·색(Gold)·등장 리듬을 바꿔 강조한다. 등장→강조 정점→읽을 정착을 설계한다. 모든 문장에 같은 팝 효과를 복제하지 않는다 |
| 화면 확대·재구도 | 핵심 장면(아이의 표정·손·작품·발표)으로 시선을 옮긴다. 자막만 흔들어 설명 동작을 대신하지 않는다 |
| 화면 전환 | 말의 다음 관계(그다음·그래서·그 결과)에 맞춰 매치·마스크·카메라 이동으로 잇는다. 매 문장마다 장면을 리셋하지 않는다 |
| 보조 그래픽 | 화살표·밑줄·일정 띠로 순서·관계·주목할 결과를 보여 준다. 장식이 사진보다 먼저 읽히지 않게 |
| BGM·효과음 | 화면 상황(등장·전환·착지)과 핵심 발화마다 소리 또는 정적의 역할을 정해 실제 믹스에 넣는다. **BGM은 이 편의 정서(차분·애잔·따뜻·감동·경쾌…)에 맞춘 곡이다** — 밝은 곡을 기본값으로 깔지 않는다(ABMEN 2026-10-21 감사 승계, 절차 `docs/14-hyperframes.md` §5·`resources/music/README.md`). 효과음 선택·크기·명료도는 `resources/sfx/README.md` |

- **한 편이 갚을 약속부터 정한다.** 학부모가 끝에 얻을 이해(아이가 여기서 하는 일)와 행동(상담·설명회)을 기준으로 사진과 사실을 고른다.
- **장면은 명사가 아니라 변화로 설계한다.** 「교실 사진·선생님 사진」 대신 「아이가 손을 들고 → 앞에 나와 → 영어로 말하고 → 친구들이 박수」처럼 쓴다.
- **보는 대상과 읽는 말을 분담한다.** 자막은 실제 발화, 사진 옆 라벨은 과정명·연령·일정, 헤드라인은 필요한 결론. 같은 뜻을 세 곳에 반복하지 않는다.
- **이동 중에도 글자가 읽혀야 한다.** 사진이 움직이는 동안 핵심 날짜·전화번호·자막이 가려지면 고친다.
- **마지막은 학부모의 행동이 남아야 한다** — 엔딩 카드(§2-3)가 그 자리다.

설계는 STORYBOARD 행의 `새 이해 | 원인과 주연의 시작→결과 | 다음 관계 | 핵심 발화/실측 초 | 자막·화면·소리 강조 | 읽을 정착/검수 시각`에 모은다. 완료 판정·검수 시점은 video ④·⑤가 정본이다. 화소 변화율·트윈 수·효과음 수는 진단 참고이고 목표치가 아니다.

## 4. 제작 경로 — ABMEN과 다른 점

| 소재 | 경로 | 비고 |
|---|---|---|
| **원생·교실·선생님·수업 결과** | **학원이 준 실제 사진·영상만** (`photo-intake`) | 🔴 생성·합성 금지 — 실제처럼 보이는 합성 원생은 기만 광고(02 §1-3·§1-4) |
| 배경·소품·계절 장식(호박·눈송이 등)·설명 그림 | 코드 그래픽 또는 이미지 생성(video ② `asset-prompts --generate`) | 생성물에 아이·교실을 넣지 않는다. 프롬프트에 `no people, no children` 명시 |
| 지점 외관·위치 | 학원이 준 사진, 또는 지도 없이 주소 텍스트 | 저작자 표시가 필요한 지도·사진(OSM·Commons)은 ABMEN 규칙대로 쓰지 않는다 |
| YBM ECC 마크 | `resources/brand/ybmecc-mark.svg` | 무변형 |
| 과정표·일정·반 구성 | 코드 2D 도식 | 원장 확인값 |

ABMEN의 「실재 대상은 ref-photos로 실물 대조 후 사진풍 생성」 규칙은 장소·소품을 생성할 때만 해당한다 — 원생 사진은 생성하지 않으므로 대조 대상이 아니다. Blender 3D·셰이더는 ABMEN 규칙 그대로 선택 재료다(사진의 아이를 3D로 재현하지 않는다).

`pipeline/new.sh <슬러그>`가 Ivory 무대·Pretendard·좌상단 로고 골격을 만든다. 토큰은 `brand.json`, 로고 적용은 `pipeline/root-lockup.mjs`. 루트의 `abmen-headline`·`abmen-body`·`abmen-number`·`abmen-label`·`abmen-caption`·`abmen-poster-title` 클래스 이름은 ABMEN 호환으로 그대로 둔다(값은 brand.json).

## 5. 이력

- 2026-10-20 ABMEN에서 이식. 로고 3안(A 가로·B 세로 스택·C 탭) 비교 시트를 사용자에게 보였고 C를 기본값으로 정했다 — 사용자 선택이 오면 이 줄을 고친다. 기준 시안은 첫 편 제작 뒤 지정한다.
