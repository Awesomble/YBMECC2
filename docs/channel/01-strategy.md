# 01. 전략 — 대치동 학부모에게 「여기서 우리 아이가 하는 일」을 보여 준다

개정일 2026-10-20 (ABMEN 이식). 지점 사실은 [07 Y01](07-evidence.md)에서 확인한 값만 쓴다.

## 1. 채널의 약속

- **보여 준다, 주장하지 않는다.** 원생이 실제로 말하고 발표하고 만드는 장면이 증거다. 「최고」「1위」 대신 「오늘 IVY Kids 반이 한 일」을 보여 준다.
- **한 편 한 가지.** 한 영상은 한 활동·한 과정·한 행사·한 안내(설명회·모집·레벨테스트) 중 하나만 이해시킨다.
- **법이 요구하는 것을 숨기지 않는다.** 상호·등록번호·교습과정은 영상 엔딩에, 교습비는 문안에 늘 같은 자리에 둔다(02 §1-1). 브랜드에 대한 신뢰는 거기서 시작한다.

## 2. 누구에게 말하는가

| 대상 | 무엇을 궁금해하나 | 영상이 답할 것 |
|---|---|---|
| 5~7세 자녀 학부모 (IVY Kids·IVY Friends) | 영어 환경에서 아이가 즐겁게 지내는지, 하루가 어떻게 흘러가는지, 선생님은 어떤지 | 실제 수업·놀이·발표 장면, 하루 흐름, 반 구성 |
| 초등 학부모 (IVY Master·초등부) | 말하기·읽기·쓰기가 어떻게 쌓이는지, 지금 수준에서 무엇을 하는지 | 활동 과정(발표·토론·프로젝트), 레벨테스트 절차 |
| 대치·도곡·역삼 인근 이사·전학 가정 | 위치·셔틀·상담 방법 | 오시는 길, 상담 예약 방법(대표번호) |

🔴 **「학년보다 앞서」를 약속하지 않는다** — 선행학습 유발 광고는 학원에 금지다(02 §1-2). 「지금 단계에서 깊이」「말로 표현하는 힘」처럼 아이가 현재 하는 활동으로 말한다.

## 3. 목표와 측정

- **목표 행동:** 상담 예약 전화(02-553-0509)·설명회 신청·레벨테스트 문의·인스타 DM. 조회수는 수단이다.
- **측정:** 업로드 72시간 뒤 플랫폼 지표(도달·평균 시청 시간·공유·저장·프로필 방문) + 원장이 받은 문의 수를 프로젝트 README 업로드 기록에 함께 적는다. 「문의가 어디서 왔는지」를 상담 때 한 줄로 묻도록 원장에게 제안한다(06 §3).
- 흥행 목표는 있지만 합격 수치·상한은 두지 않는다(CLAUDE.md).

## 4. 콘텐츠 범위

| 유형 | 예 | 주의 |
|---|---|---|
| 수업 현장 | 원어민 선생님과 발표, 파닉스 놀이, 리딩 서클 | 사진 동의 ✅ 원생만 (02 §1-4) |
| 행사 하이라이트 | 할로윈·스피치 대회·졸업 발표·프로젝트 전시 | 실적·수상은 이 지점·이 행사의 실제 값만 (02 §1-3) |
| 모집·설명회 안내 | 신학기 모집, 설명회 일정, 레벨테스트 | 마감·잔여석은 원장이 확인한 실제 값만 — 없는 시한은 허위 긴급성 |
| 과정 소개 | IVY Kids 하루, IVY Master 한 주 | 과정명은 공식 표기(IVY Kids·IVY Friends·IVY Master·iLearning), 「유치원」 명칭 금지 (02 §1-5) |
| 선생님·공간 소개 | 교실·도서 공간·선생님 인사 | 선생님 얼굴·이름도 본인 동의 |
| 학부모 정보 | 영어 그림책 고르는 법, 집에서 하는 말하기 놀이 | 학원 광고와 정보의 경계 — 끝에 지점 안내를 붙이면 광고다(법정 표시 동일) |

하지 않는 것: 다른 학원·지점과의 비교 광고, 성적·합격 실적을 앞세운 영상, 본사 전국 실적을 지점 실적처럼 쓰는 영상, 원생을 생성 이미지로 만든 장면.

## 5. 편집 참고

학원 숏폼은 「사진 몇 장 + 배경음 + 자막」 슬라이드가 기본값이 되기 쉽다. 이 채널은 ABMEN의 첫 3초 원칙(CLAUDE.md 최우선)을 그대로 쓴다 — **0초 포스터**는 이 편의 주제(예: 「7살이 영어로 발표하는 날」)·후킹(아이가 실제로 해낸 장면의 값)·키 비주얼(가장 표정이 사는 사진)이 한 장에 들어간 것이다. 사진은 움직임으로 읽힌다: 확대·이동·마스크 전환·사진 속 아이 손끝으로 이어지는 포인터(05 §3).
