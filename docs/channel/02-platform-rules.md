# 02. 법규와 플랫폼 — 학원 광고가 지킬 것

개정일 2026-10-20. 조문은 법제처 국가법령정보 공동활용 API의 현행 원문을 조사 에이전트가 읽었고, 하드 검사의 근거인 학원법 제15조제3항·시행령 제16조의3·공교육정상화법 제8조제4항은 메인이 원문을 직접 대조했다(구분과 일련번호는 [07 Y02~Y07](07-evidence.md)). **법률 자문이 아니다** — 파이프라인 기본값을 보수적으로 정한 근거다. 해석이 갈리는 것은 「해석 필요」로 표시하고 원장·강남서초교육지원청 확인을 프로젝트 README에 남긴다.

검사는 코드가 한다: `node pipeline/academy-check.mjs <p>` · `stage-gate.mjs` 🏫 절 · `publish-check.mjs`. 표현 규칙의 정본은 `pipeline/lib/platforms.json` `academy_ad`, 지점 값의 정본은 `pipeline/templates/brand.json` `academy`.

## 1. 학원 광고 법규

### 1-1. 법정 표시 — 상호·등록번호·교습과정·교습비

| 근거 | 요구 |
|---|---|
| 학원법 제15조제3항 | 학습자 모집 목적으로 인쇄물·인터넷 등으로 광고하면 교습비등과 등록증명서 내용 중 대통령령이 정한 사항을 표시 |
| 학원법 시행령 제16조의3 | 1. 등록번호 2. 학원 명칭 3. 교습과정(교습과목) |
| 서울특별시교육청 학원 조례 시행규칙 제8조제2항 | 광고에 교습과정의 **반당정원·월교습시간·월교습비·교습기간·기타경비**(모의고사비·재료비·피복비·급식비·기숙사비·차량비) 내역을 학습자가 쉽게 확인할 수 있게 |
| 학원법 제15조제4항 · 제23조제1항제7호 | 교습비 거짓 표시 금지 · 미표시·거짓 표시 300만원 이하 과태료 |
| 학원법 제17조제1항제9호 | 학습자 모집 때 과대·거짓 광고 → 등록 말소 또는 1년 이내 교습정지 |

**파이프라인 기본값:**
- **영상 엔딩 카드**에 상호 「이씨씨대치어학학원」·「학원 등록번호 제3984호」·교습과정을 휴대폰에서 읽히는 크기로(05 §2-3). ⑤부터 하드.
- **업로드 문안**(인스타 캡션·유튜브 설명·카드 캡션) 끝에 법정 표시 블록 — 상호·등록번호·교습과정·교습비 5항목(review 스킬 「학원 법정 표시 블록」). ⑥에서 하드.
- 교습비·교습과정 값은 **원장 확인본만**(brand.json `academy.tuition`·`courses`). 비어 있으면 업로드 단계가 막힌다.
- 해석 필요: 숏폼 영상이 조례의 「광고」에서 교습비를 캡션에만 둬도 되는지. 그래서 영상에는 최소 3항목, 문안에는 전 항목을 둔다. 교습비까지 영상에 넣으라는 지침이 오면 엔딩 카드에 표로 더한다.
- 사업자등록번호·대표자 이름은 법정 표시 항목이 아니다 — 영상에 넣지 않는다.

### 1-2. 선행학습 유발 광고 금지

공교육 정상화 촉진 및 선행교육 규제에 관한 특별법 **제8조제4항**: 「학원, 교습소 또는 개인과외교습자는 선행학습을 유발하는 광고 또는 선전을 하여서는 아니 된다.」(선행학습 = 국가·시도·학교 교육과정보다 앞선 학습, 제2조제3호). 영어 학원 과정은 제16조 적용 배제 목록에 없다. 교육부 예시: 「초등 때 중등 과정을 마쳐야 합니다」.

→ **하드:** 「선행」, 「중등 과정을 미리/마쳐/끝낸」, 「N학년 앞서」 류. 「선행학습을 하지 않습니다」처럼 부정하는 말은 해당하지 않는다. 대신 쓸 말: 「지금 단계에서 깊이」, 「말로 표현하는 힘」, 「수준별 반」.

### 1-3. 거짓·과장·기만 — 최상급·실적·후기

- 표시광고법 제3조제1항(거짓·과장·기만·부당 비교·비방 금지), 제5조제1항(사실 관련 사항은 실증할 수 있어야), 제17조(2년 이하 징역·1억5천만원 이하 벌금).
- 공정위 「기만적인 표시·광고 심사지침」(2025-10-30 시행): 「수강생 수 1위」 등을 쓰면서 근거를 작게·인식하기 어렵게 표시하면 기만. 특정 시기 1위를 계속 1위처럼 쓰는 것도 문제.
- 공정위 2023-12 학원·출판사 9곳 18.3억원 과징금 — 합격생 수 부풀림, 근거 없는 「최다 1등급 배출」「압도적 1위」.
- 「추천·보증 심사지침」: 후기는 실제 경험이어야 하고 가공·재구성 금지, 경제적 대가는 매번 표시.

→ **하드:** 결과 보장(「성적 향상 보장」「무조건 합격」「100% 향상」). **경고(근거가 README 확정 팩트에 있을 때만):** 1위·최고·최초·최다·유일·압도적, 합격·배출·수상, 본사 문구(「모국어처럼」「결과로 증명」), 후기·추천, 모집 긴급성(마감 임박·선착순·잔여석). 근거는 화면 같은 크기·같은 장면에 밝힌다. 본사·다른 지점 실적을 지점 실적처럼 쓰지 않는다.

### 1-4. 원생 사진·영상 — 개인정보와 동의

- 개인정보 보호법 제2조제1호가목: 영상 등으로 개인을 알아볼 수 있는 정보도 개인정보. 제15조제2항: 동의 때 목적·항목·보유 기간·거부권 고지. **제22조의2**: 만 14세 미만 아동은 **법정대리인 동의**를 받고 동의 여부를 확인해야 한다.
- 개인정보보호위원회 「아동·청소년 개인정보 보호 가이드라인」(2022.7): 법정대리인 동의 절차(2-1항). 홍보물 사용에 대한 사업자 사례는 없다 — 그래서 보수적으로 정한다.

**파이프라인 기본값 (photo-intake·academy-check가 막는다):**
1. 보호자 **서면 동의**(홍보 목적·게시 매체·게시 기간·철회 방법이 적힌 것)가 있는 원생만. 입학 동의서가 홍보 사용을 포함하는지는 원장 확인.
2. 사진은 `projects/<p>/photos-in/`에 넣고 `node pipeline/photo-intake.mjs <p>` — 회전 적용·축소·**위치(GPS)·기기 정보 삭제** 사본만 `assets/photos/`에. 원본·사본 모두 **git에 올리지 않는다**(동의 철회 때 git 이력에서 지울 수 없다).
3. README 「## 사진 동의」 표에 모든 사진 한 줄 — 동의 칸 ✅만 화면에 쓴다. 인물이 없는 사진도 「✅ 인물 없음」.
4. 이름표·교복 학교명·셔틀 번호·집 주변처럼 아이를 찾을 수 있는 정보는 화면에서 가린다(크롭·흐림). 자막·문안에 원생 실명을 쓰지 않는다.
5. 동의 철회가 오면 그 아이가 나온 게시물을 내리고 사본을 지운다 — 업로드 기록(README)에 어느 편에 누가 나왔는지 사진 파일 단위로 남아 있어야 찾을 수 있다.
6. 🔴 **원생·교실·선생님·수업 결과를 생성 이미지로 만들지 않는다.** 실제처럼 보이는 합성 원생은 기만 광고이자 실존 아동처럼 오인된다. 생성은 배경·소품·설명 그림(05 §4).

### 1-5. 유치원(유사) 명칭

유아교육법 제28조의2: 유치원이 아닌 곳은 유치원 또는 유사한 명칭을 쓰지 못한다(제35조제1항 500만원 이하 과태료). 교육부도 「학원은 유치원 또는 유치원과 유사한 명칭 사용 금지」를 안내한다.

→ **하드:** 「영어유치원」「영유」「유치원 과정/반/부」. **경고:** 「영어유치부」 — 본사 공식 과정명 표기에 쓰이지만 유사 명칭 해석 미확인, 원장·교육지원청 확인 전에는 「IVY Kids(5~7세 과정)」. 「유치원 하원 후」처럼 다른 기관을 가리키는 말은 해당하지 않는다.

### 1-6. YouTube 「아동용(made for kids)」 설정

YouTube는 위치와 무관하게 모든 영상에 아동용 여부를 정하게 하고, 판단 요소로 아동 출연자, 아이가 이해하게 만든 말, 놀이·간단한 노래·조기 교육 같은 활동을 든다. 일반 시청층 예시는 「다른 부모에게 놀이공원 방문을 알려 주는 가족 브이로그」.

→ 학부모 정보 중심(과정·일정·상담 안내)이면 「아동용 아님」이 후보, 원생의 노래·챈트·놀이가 영상 중심이면 아동용 가능성 — **최종 선택은 사용자**가 하고 판단 근거 컷을 README ⑥ 절에 적는다. 아동용으로 지정하면 댓글·맞춤 광고 등이 제한된다.

### 1-7. Meta(인스타그램) 광고

Meta 광고 표준은 아동을 성적으로 착취하거나 위험에 빠뜨리는 내용을 금지하고 광고의 노출(nudity)을 금지한다. 교육·학원을 따로 제한하는 범주는 정책 목차에서 찾지 못했다. 일반 게시물과 **유료 광고 집행(부스트)**은 따로 점검한다 — 집행할 때는 Meta 광고 관리자 화면의 현재 정책을 다시 본다.

### 1-8. 브랜드·음성·음악 사용 조건

- **YBM ECC 마크:** ybmecc.com 헤더의 공식 SVG를 무변형으로 쓰고 지점 표기(「대치점」)만 옆에 조판했다. 가맹점 홍보물의 CI 사용 승인 절차·가이드는 확인하지 못했다 — **가맹본부 가이드 확인 필요**(01 §6).
- **타입캐스트(유료 AI 목소리):** 2026-09-05 보존 이용정책(`legal/typecast-2026-09-05/usage-policy-ko.html`)에 「본사 이외의 지점·분원을 별도로 두고 있다면 지사는 본사와 별도로 구분하여 가입」, 「사업자 등록이 구분되어 있다면 각 사업자별로 가입」이 있다. **대치점 광고에 쓰는 음성을 어느 사업자 명의 구독으로 만들지 사용자 확인 전에는 유료 합성하지 않는다**(무료 `say` 길이 측정은 가능).
- **BGM·효과음:** stage-gate 5가 CC0가 아닌 곡을 막는다. CC0·Pixabay Content License는 상업 광고에도 쓸 수 있다. 「YouTube 오디오 보관함」처럼 플랫폼 한정 라이선스 곡은 인스타·광고 집행에 쓰지 않는다.

## 3. 게시처

기본 게시처는 **인스타그램 릴스(페이스북·스레드 교차 게시)와 유튜브 쇼츠**다(brand.json `platforms`). 틱톡·X는 학부모 도달이 낮고, 교습비 등 법정 표시를 넣을 본문이 모자라 기본에서 뺐다 — 사용자가 요청하면 그 편만 쓰되 같은 법정 표시를 첫 답글이 아닌 본문에 둔다. 네이버 블로그·플레이스·카카오 채널은 문안 파이프라인 밖이다(요청 시 README ⑥ 절에 따로 쓴다).

## 4. 실무 기준

- 출처·확인일·URL은 README 확정 팩트에만, **업로드 문안에는 넣지 않는다**(ABMEN 2026-10-02 규칙 승계 — publish-check가 막는다). 대표번호·주소는 출처가 아니라 법정·안내 정보라 문안에 쓴다.
- 지점이 바뀌는 값(교습비·일정·반 편성)은 편마다 원장 확인 날짜를 README에 적는다. 오래된 값을 새 편에 복사하지 않는다.
- 이 문서는 게시를 추가 승인 단계로 만드는 규칙이 아니다. 제작 승인 범위를 따른다.

## 5. 업로드 설정과 노출 (ABMEN 2026-10-06 조사 중 학원 편에 쓰는 것)
