## 2. 제작 전 확인 (편마다 README 「확인이 필요한 사실」)

1. 사진 속 원생 전원 보호자 서면 동의(범위: 인스타·유튜브·기간) — `photo-intake --check` 통과.
2. 이 편이 말하는 활동·과정명·연령·날짜 — 원장 확인 날짜와 함께.
3. 지점 공통 값(교습과정·교습비 5항목)이 brand.json `academy`에 채워졌나 — `academy-check`.
4. 목소리: 타입캐스트를 쓸지, 쓴다면 어느 사업자 명의 구독인지(02 §1-8). 미정이면 무료 `say`로 길이만 맞춘다.
5. YouTube 아동용 설정 판단 근거(02 §1-6) — ⑥에서 사용자에게.
