# YBMECC — YBM ECC 대치점 학원 홍보 숏폼 지침

개정일: **2026-10-20** (ABMEN에서 이식). 제작 파이프라인(①~⑥·검사·렌더)은 ABMEN과 같고, **누구에게·무엇을·어떤 법 안에서** 보여 주는지는 이 폴더가 정본이다.

**설명 관점: 대치동 학부모가 「우리 아이가 여기서 무엇을 하게 되는지」를 짧은 영상 한 편 안에 눈으로 이해하게 한다(길이 상한·목표 수치는 두지 않는다 — CLAUDE.md).** 주연은 원생의 실제 수업·행사 사진이고, 2D 그래픽은 그 사진이 보여 주는 활동·과정·일정을 읽게 돕는 띠·숫자·포인터다. 목표 행동은 상담 예약·설명회·레벨테스트 문의다.

**세 가지는 기법이 아니라 납품 조건이다** — 코드가 막는다(`node pipeline/academy-check.mjs <p>`, stage-gate 🏫 절):
1. **법정 표시** — 상호 「이씨씨대치어학학원」·학원 등록번호·교습과정은 영상 엔딩에, 교습비 5항목까지는 업로드 문안에([02 §1-1](02-platform-rules.md)).
2. **금지 표현** — 선행학습 유발·유치원(유사) 명칭·결과 보장은 쓰지 않고, 최상급·실적·후기는 근거가 있을 때만([02 §1-2·§1-3·§1-5](02-platform-rules.md)).
3. **원생 사진 동의** — 보호자 서면 동의가 README 「## 사진 동의」에 ✅로 있는 사진만 화면에 쓴다. 아이를 생성 이미지로 만들지 않는다([02 §1-4](02-platform-rules.md)).

## 근거의 구분

- **확인:** 법제처 원문·정부 기관·ybmecc.com 공식 페이지에서 직접 확인한 내용. 조문 번호·URL·확인일을 07 Y절에 남긴다.
- **원장 확인:** 교습비·교습과정·행사 일정·수업 사실처럼 지점만 아는 값. `pipeline/templates/brand.json` `academy`(지점 공통)와 프로젝트 README(편마다)에 적는다.
- **해석 필요:** 영상 광고에서 교습비를 캡션에만 둬도 되는지, 「영어유치부」 표기처럼 공식 해석을 못 찾은 것. 보수적으로 만들고 원장·강남서초교육지원청 확인을 README에 남긴다.

이 문서들은 법률 자문이 아니다. 조문과 공식 안내를 읽고 파이프라인 기본값을 보수적으로 정한 것이다.

## 제작과의 관계

기술·안전영역·음성 동기·렌더 검사는 `CLAUDE.md`와 `docs/`의 ABMEN 이식 규격을 따른다. 영상 제작은 공용 `/video`(`$video`) 스킬 ①~⑥이다. **ABMEN의 「외부 사진 금지·장소는 생성 이미지」 규칙은 이 채널에서 뒤집힌다** — 원생·교실·행사는 학원이 준 실제 사진이 주연이고, 생성 이미지는 배경·소품·설명 그림에만 쓴다([05 §4](05-brand-pipeline.md)). 컨셉 확정·문서 정리만으로 음성·모션·MP4 제작을 시작하지 않는다.
