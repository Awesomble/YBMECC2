# 시나리오 — AI 티가 나지 않게 쓰는 법

**"찍어낸 티가 나나"가 유튜브의 판정 기준이다** (`03-strategy.md` §2).
AI 로 만드는 것 자체는 금지가 아니다. 문제는 **AI 가 쓴 티**다.

이 문서는 두 갈래를 합친 것이다.

- **구조** — 무엇을 어떤 순서로 말할지 (`05-shorts.md`)
- **문체** — 어떻게 말해야 사람이 쓴 것처럼 들리는지 (아래)

---

## 0. 참고한 자료

문체 규칙은 **[epoko77-ai/im-not-ai](https://github.com/epoko77-ai/im-not-ai)** (MIT, ★4.8k)를
분석해 **숏폼 나레이션에 해당하는 것만 골라낸 것**이다.

> AI 가 쓴 한글을 사람 글처럼 윤문하는 도구. 한글 AI 글의 특징이 대부분 **영어 번역투**에서
> 온다는 관찰에서 출발해, 10대 카테고리 71개 패턴을 심각도(S1~S3)로 정리했다.

**도구를 설치해 쓴 게 아니라 분류 체계만 참고했다.** 원 저장소는 칼럼·리포트 기준이라
말로 하는 짧은 나레이션에는 그대로 적용되지 않는다.

그쪽 4대 철칙 중 우리에게도 그대로 유효한 것:

| | |
|---|---|
| **의미 불변** | 사실·수치·고유명사는 손대지 않는다 |
| **과윤문 금지** | 자연스럽게 만들려다 내용을 흐리면 실패다 |

## 1. 나레이션에 치명적인 패턴 — 우선순위 순

귀로 듣는 글이라 **글로 볼 때보다 티가 더 난다.** 리듬이 들리기 때문이다.

### 🔴 S1 — 하나만 나와도 AI 티

**기계적 열거 — "첫째 / 둘째 / 셋째"**

가장 흔하고 가장 확실한 AI 표식이다. 사람은 말할 때 이렇게 세지 않는다.

```
❌ 첫째, 갱신 가격을 확인하십시오. / 둘째, ... / 셋째, ...
✅ 먼저 갱신 가격을 확인합니다. / 다음은 후이즈 프라이버시. / 마지막은 도메인 종류입니다.
```

**열거 도입 — "세 가지가 있습니다", "다음과 같습니다"**

```
❌ 확인할 게 세 가지 있습니다.
✅ (바로 본론으로) 갱신 가격부터 확인합니다.
```

**결산 표현 — "결론적으로", "정리하자면", "요약하면"**

이미 말한 내용을 끝에서 다시 요약하는 결산 도입은 덜어낸다. **첫 3초에 결과를 선언하는 훅은 다르다.** §7처럼 결과를 먼저 던지고 본문에서 뜻·근거·조건을 설명한다.

**이중 피동 — "판단되어진다", "만들어지게 된다"**

```
❌ AI 에 의해 생성된 이미지
✅ AI 가 만든 이미지
```

### 🟠 S2 — 반복되면 티가 난다

**문장 길이가 균일하다** — 나레이션에서 가장 잘 들린다

전부 20~25자로 맞춰져 있으면 기계가 읽는 것처럼 들린다.
**짧은 문장 사이에 긴 문장을 하나 섞어라.**

```
❌ 20자 / 22자 / 21자 / 24자 / 23자
✅ 9자 / 31자 / 14자 / 12자 / 27자
```

**종결어미가 반복된다**

"~습니다"만 다섯 번 이어지면 들린다.
평서·격식 있는 명령·짧은 명사종결과 문장 길이·호흡을 문맥에 맞게 바꿔라. 발화 대사의 `-요` 종결과 의문형은 제외한다.

```
❌ 확인합니다 / 살펴봅니다 / 확보합니다 / 절약합니다
✅ 갱신가 확인이 먼저입니다 / 무료 제공 여부도 따집니다 / .com부터 / 여기서 비용이 갈립니다
```

**hedging — "~하는 경우가 많습니다", "~로 보입니다"**

숏폼은 단언해야 힘이 산다. 근거가 있으면 단언하고, 없으면 그 말을 빼라.

```
❌ 두 배 넘게 오르는 경우가 많습니다.
✅ 두 배 넘게 오릅니다.
```

**"~할 수 있습니다" 남발** → 단언으로. **"~에 대해"** → 목적격 조사로 직결.
**"~를 통해"** → "~로", "~해서".

**형식명사 — "~라는 것입니다", "~한다는 점입니다"**

```
❌ 중요한 건 갱신가라는 점입니다.
✅ 갱신가가 중요합니다.
```

## 2. 나레이션에만 있는 규칙

원 저장소에는 없다. **말로 하는 글**이라 생기는 문제다.

- **한 문장 = 자연스러운 한 호흡.** 컷 길이는 실제 발화와 화면의 읽을 시간을 재서 정한다. 현행 음성은 조립에서 단일 1.20배속이다
- **빠른 말에는 짧은 문장이 맞는다.** 긴 문장을 빠르게 읽으면 뭉개져서 안 들린다.
  리듬을 위해 긴 문장을 하나 섞되, **그 문장에서만 잠깐 늦춰지도록** 쉼표를 넣는다
- **TTS 가 어떻게 읽을지 생각한다.** `.com` 은 "점컴"으로, `5%` 는 "오 퍼센트"로 써야 제대로 읽는다
- **귀로 헷갈리는 말을 피한다.** 동음이의어, 비슷한 발음의 연속
- **옛 라디오 진행자의 말맛을 유지한다.** 훅·반전·유머는 어휘·비유·호흡·짧은 명사형으로 살린다. 발화 대사의 `-요` 종결과 질문형은 쓰지 않는다. 그렇다고 모든 문장을 “습니다·입니다”로 고치지는 않는다 (`docs/12-brand.md`).
- **말줄임과 조사 생략은 오히려 자연스럽다.** "도메인, 첫해 가격만 보면 손해입니다" 처럼
- **숫자는 소리 내어 읽어본다.** "1,900원"보다 "천구백 원"이 들리기 좋을 때가 있다

## 3. 그리고 가장 중요한 것 — 경험

문체를 아무리 다듬어도 **"알아본 것"과 "해본 것"은 3초 만에 구분된다** (`03-strategy.md` §6).

유튜브가 요구하는 *original value* 가 정확히 이것이고,
AI 로 못 만드는 유일한 것도 이것이다.

```
❌ 도메인은 갱신가를 확인해야 합니다        ← 알아본 것
✅ 저는 1,900원에 샀다가 2년차에 3만 원 냈습니다  ← 해본 것
```

**시나리오를 쓸 때 "직접 겪은 한 줄"을 넣을 자리를 비워둔다.**

⚠️ **경험이 있는지 캐묻지 마라.** 사용자는 이 분야 실무자다(도메인만 20만 개 규모).
자리를 만들어 넘기면 사용자가 채운다. **다만 내가 지어내지는 않는다.**

## 4. 쓰고 나서 점검 — 소리 내어 읽는다

**눈으로 읽지 말고 입으로 읽어라.** 나레이션은 귀로 소비된다.

- [ ] "첫째/둘째/셋째" 같은 기계적 열거가 없는가
- [ ] 문장 길이와 호흡이 내용에 맞게 달라지는가
- [ ] 같은 종결어미가 기계적으로 이어져 말맛이 죽지 않는가
- [ ] 단언할 수 있는데 "~하는 경우가 많습니다"로 흐리지 않았는가
- [ ] "결론적으로 / 정리하자면 / 세 가지가 있습니다" 가 없는가
- [ ] 한 문장이 실제 낭독에서 자연스러운 한 호흡으로 들리는가
- [ ] **한 영상에 메시지가 하나인가** — 팁을 욱여넣지 않았는가
- [ ] TTS 가 잘못 읽을 표기가 없는가 (`.com`, `%`, 영문 약어)
- [ ] **직접 겪은 한 줄이 있는가**
- [ ] 수치·가격·정책은 확인했는가 (프로젝트 `README.md` 에 근거를 남긴다)

## 5. 실제 진단 사례 — `00001-도메인구입` 초안

내가 쓴 첫 대본을 위 기준으로 점검한 결과다. **세 군데가 걸렸다.**

```
1. 도메인, 첫해 가격만 보면 손해입니다.              (20자)
2. 할인이 끝나고 갱신할 때 두 배 넘게 오르는 경우가 많습니다.  (32자)
3. 첫째, 살 때 갱신 가격을 먼저 확인하세요.            (22자)
4. 둘째, 후이즈 프라이버시가 무료인지 보세요.           (24자)
5. 셋째, 브랜드 이름은 점컴부터 잡으세요.              (23자)
6. 이 세 가지만 확인해도 몇 년치 비용이 달라집니다.       (25자)
7. 온라인 사업의 첫 비용, 여기서부터 아끼세요.          (24자)
```

| | 문제 | 해당 |
|---|---|---|
| 3·4·5 | **"첫째/둘째/셋째" 기계적 열거** | 🔴 S1 |
| 6 | "이 세 가지만" — 열거 결산 | 🔴 S1 |
| 2 | "~는 경우가 많습니다" — hedging | 🟠 S2 |
| 전체 | **문장 길이가 20~25자에 몰려 있다** (2번만 예외) | 🟠 S2 |
| 전체 | 종결어미가 "~습니다 / ~세요" 둘뿐 | 🟠 S2 |
| 전체 | **직접 겪은 한 줄이 없다** | 🔴 |

**초안은 전형적인 AI 대본이다.** 정보는 맞지만 사람이 말하는 리듬이 아니다.
고친 대본은 `projects/00001-도메인구입/README.md` 의 훅 3안과 함께 관리한다.

## 6. 잘 되는 숏츠를 뜯어서 시작한다 — 백지에서 쓰지 마라

**남의 영상을 보고 구조를 역산하는 게 백지에서 쓰는 것보다 빠르고 정확하다.**
쿼터도 결제도 들지 않는다. 대본을 시작할 때 이걸 먼저 한다.

```bash
.claude/skills/video/scripts/ref.sh "<URL>"     # 저장소 루트 기준
```

타임스탬프별 대본과 컷 리듬·말 속도·정보 밀도를 계산해 준다. 거기서 **이 다섯 가지만 뽑는다.**

| | 뽑을 것 |
|---|---|
| **훅** | 첫 3초의 문장 그대로. 수치·결과·반전 중 무엇이 중심인가 |
| **컷 리듬** | 자막 타임스탬프 간격 = 컷 길이. 어디서 빨라지고 어디서 쉬는가 |
| **정보 밀도** | 몇 초에 새 정보가 하나씩 나오는가 |
| **되돌아오는 지점** | 마지막이 첫 화면으로 수렴하는가 |
| **말 속도** | 자막 글자 수 ÷ 구간 길이 |

⚠️ **가져오는 건 구조지 내용이 아니다.** 문장을 베끼면 그 채널의 AI 티까지 같이 온다.
§1 의 금지 패턴은 그대로 적용된다. 영상 파일이나 대사를 재사용하지 않는다.

⚠️ **한국어 숏츠를 참고하라.** 영어권 포맷은 말 속도와 문장 구조가 달라
그대로 옮기면 현행 1.20배속 나레이션에서도 발음과 호흡이 뭉개질 수 있다.

## 7. 훅 문형 — 첫 화면의 사건과 함께 쓴다

> 🔵 **ABMEN:** 이 절의 옛 라디오 어조·`-요` 종결·질문형 제외는 ABM 페르소나 규칙이라 적용하지 않는다. ABMEN 훅은 구성 전체에서 가장 강한 후킹을 첫 3초에 두는 video SKILL 「최우선 — 첫 1·2·3초」와 채널04 §2~3이 정본이다. 여기서는 과장 표현과 허위 사실의 경계만 참고한다.

**첫 발화부터 강한 놀라움·호기심을 만든다.** 옛 라디오 아나운서가 뜻밖의 결과나 재치 있는 과장을 던지는 느낌을 살린다 (`docs/12-brand.md` 「시작·끝 대사」). “알려드립니다” 뒤에 주제를 설명하는 데 그치지 말고, 소재의 가장 뜻밖인 결과·혜택·차이부터 꺼낸다. 채널명은 훅 뒤의 연결부에 넣거나 발화를 생략할 수 있다. `-요` 종결과 질문형·반문·자문자답 없이 어휘·비유·호흡으로 말맛을 살린다.

**강한 과장 훅 → 본문에서 정확한 뜻·조건 설명**도 허용한다 (2026-09-16 사용자 지시). 놀람의 강도, 의인화·비유, 압축된 결과로 세게 말한 뒤 본문에서 실제로 무엇을 뜻하는지 풀어준다. 모든 설명과 단서를 첫 대사에 욱여넣어 힘을 빼지 않는다. 궁금증의 답은 본문에서 전개하며, 중요한 조건은 시청자가 이해할 수 있는 대사와 화면으로 전달한다.

| 훅의 각도 | 대사 예시 | 뒤에서 풀어줄 것 |
|---|---|---|
| 의외의 혜택 | “내가 적금 넣는데, 나라가 돈을 더 얹어줍니다!” | 어떤 지원인지, 가입 대상·납입 조건·지원 범위 |
| 강한 비유 | “냉장고 속 재료들, 오늘부로 강제 합방입니다!” | 어떤 재료로 무엇을 만들며 실제로 어떻게 조합하는지 |
| 뜻밖의 비교 | “같은 물건인데, 사는 날 바꾸니 이만큼 차이 납니다!” | 확인한 가격 차이와 적용 날짜·구매 조건 |

예시는 말맛과 연결 방식의 재료이며 매 편 복사하는 문구가 아니다. **과장은 표현에 쓰고 사실의 주체·수치·효능을 새로 만들지는 않는다.** 지원금과 원금 포함 만기 총액, 현금과 포인트처럼 서로 다른 것은 구분한다. 뒤의 설명이 앞의 훅을 구체화해야 하며 “사실 그런 혜택은 없다”로 약속 자체를 뒤집는 낚시는 고친다.

작성할 때 소재에 맞는 서로 다른 각도의 훅을 비교하고 가장 강한 것을 실제 첫 `say`에 넣는다. **이 주제여야 할 말인가, 무엇이 놀랍거나 궁금한가, 본문이 그 약속을 갚는가, 옛 라디오 말맛이 남는가**를 낭독하며 확인한다. 질문형 후보는 제외하고, 후보 개수·음절 수로 합격을 판정하지 않는다. 막연한 “대박입니다·끝까지 보십시오”만 남으면 구체적인 혜택·차이·궁금증으로 다시 쓴다.

첫 프레임은 포스터다 — 주제 제목·후킹(핵심 결과)·키 비주얼(큰 주연)을 한 장에 보여주고(정본 video SKILL 「최우선」 0.0초 포스터), 3초 안에 그 결과를 주연의 사건으로 키운다. 훅의 수치·놀라는 말·반전에 동작 정점을 맞춘다. 근거·조건은 본문에서 설명하되 적용 범위를 속이지 않는다. 화면을 로고 대기나 작은 글씨가 빼곡한 정보판으로 남기지 않는다. 화면과 나레이션은 같은 의미·강조 시각을 공유한다.

### 데드에어 — 문장이 아니라 dur 를 줄여라

`dur` 를 넉넉히 잡으면 그 차이가 통째로 무음이 된다. **`dur` = 실측 발화 끝 + 0.13초.**
남는 시간이 생기면 dur 로 흡수하지 말고 문장을 늘리거나 컷을 합쳐라. 상한: 문장 간 250ms ·
컷 경계 300ms · 절대 600ms · 발화 점유율 90%+ (근거·측정법은 `05-shorts.md` §1-2).

## 8. 문장은 연결어로 잇는다 — 29편 실측이 뒤집은 것 (2026-09-04)

조회수 50만+ 정보 숏츠 29편의 자막 단어 타임스탬프를 실측한 결과(viral-audit),
**"짧은 문장을 균일하게"는 절반만 맞았다.** 참조군(1분만 ≤30초 9편)의 실제 프로필:

| 지표 | 참조군 | 초안(v3)의 실패값 |
|---|---|---|
| 문장 밀도 | **0.27문장/초** (23초에 6문장) | 0.57 (컷당 1문장 균일) |
| 척추 문장 | **최장 문장이 전체 음절의 38%** | 10% |
| 연결어 | 100음절당 1.5개 — **-고(48회)·-는데(16회)가 60%** | 0개 |
| 종결어미(참조군 관측값) | ~입니다 0개. **-거든요·-죠·-고요·-잖아** | 100음절당 2.3개 |
| 말 속도 | 조음 9.8 · 전체 8.8 음절/초 | — |

**옛 라디오 콘셉트의 말맛을 살린다.** 설명의 기본 전달감은 아나운서로 유지하되 훅·반전·유머를 전부 “습니다·입니다”로 닫지 않는다. 짧은 명사형과 어휘·비유·호흡으로 본문에도 변화를 준다. 위 참조군의 `-요` 종결·질문형은 현행 대사에 옮기지 않는다. 특정 어미의 사용 비율도 강제하지 않는다.
문체 어휘·시작과 끝은 `docs/12-brand.md`를 따른다. 연결어는 사실의 관계를 자연스럽게 설명할 때 쓴다.

**규칙**:
- 사실마다 "~입니다"로 끊지 마라. **-고 로 잇고, -는데 로 배경을 깔고, -니까 로 인과를 닫아라.**
  원인→메커니즘→결과가 **한 호흡**이어야 시청자가 컷 사이에서 스스로 잇지 않는다
- **척추 문장 하나(70~85음절)** 가 여러 컷을 관통하게 하라 — 문장이 컷 경계를 넘으면
  "페이지 넘김" 체감이 구조적으로 사라진다 (컷은 절 경계에서 끊는다)
- 검증된 골격: `-면 … -고 … -면서 … -는데 … -지/-거든` (조건→과정→전환→결과)
- **이미 아는 사실을 짚은 뒤** 새 정보를 얹어라. 새 정보만 연타하면 과부하다
- 수치는 **적게 쓰고 오래 붙들어라** — 참조군은 수치 1종을 2회 반복, 30초에 7종은 과적
- 예시 (00002 v4 척추 문장, 83음절): *"디지털 온누리상품권 얘긴데, 전통시장에서 이걸로
  결제하면 쓴 돈의 십 퍼센트가 그대로 돌아오고, 일주일에 만 원만 넘기면 되는 데다 주당
  이만 원까지 쌓이니까, 구월 네 주를 다 채우면 팔만 원이 되는 겁니다."*

## 9. 유머 — 시작과 끝을 소재에 맞게 쓴다 (2026-09-16 사용자 지시)

**첫 훅과 마지막 대사를 함께 구상한다.** 유머는 강한 시작과 끝의 말맛을 살릴 때 사용한다. 이미 강한 결과 훅에 농담을 의무로 끼워 넣지 않는다. 순서·채널명·마무리 선택의 정본은 `docs/12-brand.md`의 「시작·끝 대사」다. 예전의 훅 유머 금지·정보 컷 유머 금지·한 영상 0~1개 제한은 적용하지 않는다.

### 재료와 연결

시청자가 겪는 소재 특유의 상황, 물건의 의인화, 기대와 현실의 차이, 진지한 관제방송 어법 등을 비교한다. 옛날 말투만 바꿔 붙이는 것으로 매번 유머를 대신하지 않는다. **시작의 한마디가 본문에서 설명할 문제를 열고, 끝의 한마디가 그 결과를 받아치게** 만들면 짧아도 앞뒤가 연결된다. 앞 농담을 회수하는 방식만 고정하지 않고 독립된 끝 대사도 허용한다.

| 소재 예시 | 소재별 유머 도입 | 본문 뒤 마무리 |
|---|---|---|
| 버거 정보 | “지갑은 닫자는데 배에서 반대합니다.” | “오늘 회의는 배가 이겼습니다.” |
| 냉장고 재료 활용 | “냉장고에 재료는 있는데, 서로 초면입니다.” | “이제 한 접시에서 친해졌습니다.” |

예시는 연결 방식의 설명이다. 매 영상에 복사하는 문구 모음으로 쓰지 않는다. 최근 대본이 있으면 명사만 바뀐 같은 농담도 확인한다.

### 대본으로 구현

- **도입:** 소재별 유머·과장이 강한 훅이면 첫마디부터 사용한다. 결과 훅을 선택했다면 유머는 자연스러운 지점에 배치한다. 농담을 위한 별도 인트로를 늘리지 않고 소재와 핵심 그림을 함께 보여준다.
- **본문:** 웃음과 정보 전달이 함께 되면 사용한다. 수치·조건·마감·효능을 웃기기 위해 바꾸거나 가상의 체험을 사실처럼 말하지 않는다. 꽁트의 상황은 시청자가 연출로 알아볼 수 있게 쓴다.
- **끝:** 정보를 마친 뒤 소재별 한마디·짧은 꽁트를 우선한다. 자연스러운 대사가 없으면 본문의 결론에서 끝내도 된다. 공유 요청을 관성적으로 덧붙이지 않는다.
- **말맛과 동작:** 옛 라디오 아나운서의 진지한 어조에 어휘·비유·호흡의 변화를 준다. 웃기는 단어·반전과 화면 동작의 정점을 연결한다. 고정된 정적 대기나 별도 웃음소리를 필수로 붙이지 않는다.

검수는 **이 소재여야 통하는가, 시작에서 본문으로 자연스럽게 이어지는가, 끝의 보상이 있는가, 최근 대사와 겹치는가**로 한다. 농담을 설명하는 말은 덜고, 핵심 정보와 인물의 말맛은 살린다. 시대·지역·사람을 비하하는 방식은 쓰지 않는다. 유머 개수·문장 종결어미·고정 문구 일치로 재미를 판정하지 않는다.

## 10. 장식 문장 — **금지어를 다 피해도 남는 AI 티** (2026-09-13 · Awesomble `docs/01-3-writing.md` 에서 도입)

§1 의 S1·S2 는 **어휘**를 잡는다. 그런데 그걸 다 피해도 티가 남는다.
진짜 출처는 금지어가 아니라 **사실을 담지 않은 채 인상만 흉내 내는 문장**이다.
🔴 **grep 으로도 lint 로도 안 잡힌다.** 소리 내어 읽으며 사람이 거르는 수밖에 없다.

### 한 문장 테스트 — 사실을 설명하는 문장에 적용한다

> 이 문장은 **확인한 사람만 쓸 수 있는 1차 사실**(수치·날짜·조건·출처)을 담았나?
> 아니면 **평가·요약·장식**인가?

사실이면 둔다. 내용 없는 장식이면 **잘라내거나, 그 인상을 만든 사실로 바꾼다.** 훅의 과장·의인화와 소재별 유머는 §7·§9로 판단한다. 그 한 문장 안에 수치나 단서가 없다는 이유로 지우지 말고, 본문이 실제 뜻과 조건을 설명하는지 함께 본다.

| 유형 | ❌ 장식 (사실 0) | ✅ 그 인상을 만든 사실 |
|---|---|---|
| **평가 카피** | "쿠팡이 이번에 제대로 준비했습니다" | "기본 적립에 와우 이만 원을 더하면 정확히 오 프로입니다" |
| **의인화·무생물 행위** | "숫자가 말해 주는 것은 다릅니다" | "백구십구만 원짜리가 백팔십구만 오백 원이 됩니다" |
| **잡지 reveal** ("~한 이유는 ~에 있습니다") | "열이틀이 갈리는 이유는 색상에 있습니다" | "버건디만 십팔일 도착이고, 나머지 세 색은 삼십일입니다" |

### 🔴 네 번째 유형 — **확인한 범위 밖으로 나간 설명** (우리에게 가장 위험하다)

앞의 셋은 어휘가 티를 내지만 이건 **문장이 유창해서 티가 안 난다.** 좋은 사실 바로 뒤에 붙어
신뢰를 깎는다. 우리는 **팩트를 파는 채널**이라 이게 치명적이다.

| ❌ 근거 밖으로 나간 설명 | ✅ 확인한 범위 |
|---|---|
| "예산을 넉넉히 잡았다는 뜻입니다" (예산 규모를 확인한 적 없다) | "예산이 다하면 그 전에도 닫힙니다" |
| "버건디가 인기가 없어서 재고가 남은 겁니다" (재고 사유는 모른다) | "버건디만 십팔일 도착이고 나머지 세 색은 삼십일입니다" |
| "사실상 중복으로 받을 수 있습니다" (약관 원문을 못 봤다) | "보상금은 결제 뒤 검수를 거쳐 따로 입금됩니다" |

> **한 줄 판정**: 「이 설명, 내가 확인한 것에서 나온 것인가, 확인한 것에 내가 붙인 것인가?」

### 「A가 아니라 B」 — 틀의 반복을 조심한다

외부 대조 코퍼스 실측에서 부정 대구(`A가 아니라 B`)는 **AI 5.8 vs 사람 0.6**(1000자당, 9.2배)으로
조사한 전 패턴 중 **판별력이 가장 컸다.** 세 모델에 공통이라 특정 모델 습관도 아니다.

| 판정 | 예 |
|---|---|
| ✅ **사실 대조** — 그대로 둔다 | "적립은 사자마자가 아니라 배송이 끝나고 이레 뒤에 들어옵니다" |
| ❌ **추상 대조로 요지 선언** — 반복되면 티 | "중요한 건 가격이 아니라 날짜입니다" |

🔴 **전멸시키지 마라.** 0건을 목표로 삼으면 사실 대조까지 사라져 정보가 뭉개진다.
**한 영상에 추상 대조는 하나까지.** 나머지는 직접 단언으로 바꾼다.

### 평가 대신 **조건분기**로 쓰면 장식이 안 낀다

「무엇이 좋다」(평가) 대신 **「어떤 상황이면 무엇」**(조건분기)으로 쓰면 장식이 낄 자리가 없어진다.
정보 채널에 특히 잘 맞는다 — 시청자가 자기 경우를 찾는다.

```
❌ 알뜰폰으로 가는 쪽이 이득입니다
✅ 통신사를 그대로 두실 분은 해당이 없습니다        ← 00012 실사용
```

### ⚠️ 장식이 아닌 것 — **잘라내지 마라**

이 절을 「감정·해학을 빼라」로 읽으면 대본이 **정보 유닛의 행진**이 된다.
🔴 **00012 에서 실제로 그랬다** — 사실은 정확한데 클로징이 건조했고, 사용자가 *"유머 어디갔어? 이 어색한 마감은 뭐야?"* 라고 지적했다.

| 살린다 | 예 |
|---|---|
| 본문에서 설명하는 강한 훅 | 과장·비유·결과 선언으로 관심을 끌고 실제 의미·조건을 본문에서 풀어주는 대사 (§7) |
| 소재별 시작·끝 대사 | 본문의 상황을 열고 결과를 받아치는 유머·꽁트 (§9) |
| 소재에 어울리는 선택형 공유 멘트 | 대사의 내용과 어조에 맞을 때만 넣고 자동으로 덧붙이지 않는다 |
| 옛날 어휘 한 단어 | 자그마치 · 족합니다 · 대목 · 고스란히 |
| 정직한 단서 | "예산이 다하면 그 전에도 닫힙니다" |

> **한 줄 판정**: 「이 문장을 지우면 **정보가** 줄어드나, **사람이** 줄어드나?」
> 정보가 안 줄고 사람만 줄면 **남긴다.**

### 🔴 우리 톤과 충돌하는 것 — 원문 가이드를 그대로 가져오지 마라

원 저장소(Awesomble)는 **여행·맛집 1인칭 체험 블로그**다. 우리는 **옛 라디오 진행자가 정보를 전하는 영상**이다.
말투는 현행 브랜드 지침에 맞게 적용한다:

| 원문 규칙 | 우리는 |
|---|---|
| 「딱딱한 문어체 → 평이한 현대어」 | 이해를 막는 표현은 쉽게 고치고 훅·반전은 어휘·비유·호흡으로 살린다. 기본 옛 라디오 전달감은 유지한다 (`docs/12-brand.md`) |
| 「요즘 한국어 어휘로」 | 자그마치·족합니다·대목 같은 옛말을 살리되 강한 훅을 막는 규칙으로 쓰지 않는다 |
| 1인칭 체험·감각 묘사 | ❌ 우리는 겪은 사람이 아니라 **알려주는 사람**이다 |
| 100자+ 긴 호흡 문장 | ❌ 숏폼은 한 문장 한 호흡이다 (§2). 대신 **척추 문장 70~85음절**로 리듬을 만든다 (§8) |

| 원문 규칙 | 우리도 |
|---|---|
| 습니다체 통일 | 일괄 적용하지 않는다. 아나운서 설명과 짧은 명사형·호흡 변화를 함께 살린다 |
| 리듬 변주 (짧은 문장 + 긴 문장) | ✅ §1 S2 와 같은 말 |
| 명사화·「~것」 절제 | ✅ §1 S2 형식명사와 같은 말 |
| **접속부사 절제** (또한·게다가·무엇보다·특히·사실·결국) | ✅ 새로 추가한다 |

🔴 **접속부사와 연결어미를 헷갈리지 마라.** §8 이 권하는 것은 **연결어미**(`-고` · `-는데` · `-니까`)로
문장을 잇는 것이고, 여기서 절제하라는 것은 **접속부사**(또한·게다가·무엇보다)다. **정반대 물건이다.**
