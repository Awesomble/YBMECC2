## 0. 네가 만드는 것

기본은 `projects/<p>/hyperframes/compositions/frames/*.html`에 그림과 모션을 직접 작성한다. 카탈로그에 없는 동작도 만들 수 있다. `choreo.json`·`hf-compile.mjs`는 시안 또는 기존 컴파일러 프로젝트용 선택지이며, 직접 작성한 프레임 위에 재컴파일하지 않는다.

**에셋을 전부 코드로 그리라는 뜻은 아니다.** README의 에셋 제작 경로를 따르고, 생성 이미지가 장면 품질을 높이겠다면 사용 장면·이유·완성 프롬프트를 메인에게 전달한다(메인이 `asset-prompts --generate`로 만든다). 생성된 이미지는 코드로 배치·마스크·레이어 모션을 입힌다. 생성 중에는 독립 작업을 진행하며 임시 그림을 최종본으로 처리하지 않는다.

컷 구조와 발화 의미를 보고 타이밍을 정한다. 섹션 수·컷 길이·이동량·트윈 개수의 고정 목표는 없다. 직접 작성한 프레임은 런타임에서 seek 가능한 타임라인과 클립 계약을 지킨다.

컴파일러의 자동 보정은 선택사항이다: 프레임 `autoEntry:true`는 등장 당기기, `carry:true`는 이전 컷의 동일 요소 재등장 생략, 샷 `cascade:true`는 자식의 순차 등장을 요청한다. 생략하면 지정한 샷을 보존한다.

## 2. 동사 — 기본 13개 + `raw`

| 종류 | 동사 | 언제 |
|---|---|---|
| 이동 | `in` `out` `shift` `rise` `slam` | 들어오고·나가고·자리를 옮긴다 |
| 배율 | `pop` `punch` | 강조. 횟수 자유 |
| 드러내기 | `wipe` `fill` `strike` | 가리개가 걷힌다·채워진다·긋는다 |
| 색·명도 | `tint` `dim` | 상태가 바뀐다 |
| 흔들림 | `shake` | 내용에 맞는 흔들림. 횟수 자유 |
| **자유** | **`raw`** | **위 13개로 안 되는 전부.** 룰 레시피는 이걸로 쓴다 |

🔴 **`raw` 를 쓴다고 어휘가 늘지 않는다.** 00015 는 `raw` 80회를 썼는데 전부 `clipPath`+`rotationY` 라
어휘가 그대로였다. **문장이 하는 일 → 룰 → raw** 로 옮겨라. 짝 넷:

```json
// 증감 — 막대가 자란다 (stat-bars-and-fills). 버거킹의 height 164 가 이거다
{ "el":"bar1", "verb":"raw", "t":0.4, "dur":0.6, "ease":"<서명>",
  "from": { "scaleY":0, "transformOrigin":"bottom center" }, "to": { "scaleY":1 } }

// 경로 — 선이 스스로 그려진다 (svg-path-draw). 게이지·서명·경로에
{ "el":"gauge", "verb":"raw", "t":0.2, "dur":0.9, "ease":"<서명>",
  "from": { "strokeDashoffset":1200 }, "to": { "strokeDashoffset":0 } }

// 비교 — 두 카드가 반대로 기울어 마주본다 (split-tilt-cards). 버거킹의 rotation 46 이 이거다
//   ⚠️ 이미 보이는 카드가 **기울기만 바뀌는** 것 → from 없이 to 만. (from 을 주면 등장으로 취급돼 큐 전엔 숨는다)
{ "el":"cardA", "verb":"raw", "t":0.3, "dur":0.5, "ease":"<서명>", "to": { "rotationY":-6, "transformOrigin":"right center" } }

// 분해 — 한 변을 붙박은 채 한 축으로 늘어난다 (anchored-layout-expand). 버거킹의 width 109
{ "el":"panel", "verb":"raw", "t":0.5, "dur":0.7, "ease":"<서명>",
  "from": { "scaleX":0.35, "transformOrigin":"left center" }, "to": { "scaleX":1 } }
```

🔴 **`from` 이 있으면 등장이다 — 큐 전엔 숨는다.** `from` 없이 `to` 만 주면 상태 변화다 — CSS 정지 상태에서 출발한다.
bbq 에서 `from: {scaleX:0.7}` 을 준 글자가 **큐까지 1.78초 찌그러진 채 보였다.** 사람 눈엔 오류다. 컴파일러가 이제 숨기지만,
이 초기화는 컴파일러의 기본 동작이다. 보이는 상태에서 변형하는 연출은 직접 작성한 GSAP으로 자유롭게 구현한다.

`raw` 는 임의 GSAP 속성을 통과시킨다 — `scaleX/Y`·`strokeDashoffset`·`rotationX/Y`·`clipPath`·`filter`·`skewX`·`attr`.
**같은 속성만 돌려쓰면 그건 다른 동사가 아니다.** 룰마다 물리가 다르다.
계약 셋은 컴파일러가 강제한다: **`to` 필수 · 유한한 시작/길이 · 결정론**(`random(` 류 거부).
