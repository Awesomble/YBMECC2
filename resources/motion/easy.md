# Easy — 한 속성으로 끝나는 것

승인본 6편 실측 상위: `y` 507회 · `scale` 322 · `opacity` 277 · `x` 270 · `autoAlpha` 156.
**여기서 시작하되 여기서 끝내지 마라.** 이것만 쓰면 「죄다 좌우상하」가 된다 — 그게 반려 사유였다.

---

## E1. 들어와서 딱 멈춘다

가장 많이 쓴 한 줄. `expo.out` 은 빠르게 들어와 멈추는 가속이라 **마감·정각**을 다루는 편에 맞는다.

```js
tl.fromTo('#f02-head', { y: -100, autoAlpha: 0 },
                       { y: 0, autoAlpha: 1, duration: .38, ease: 'expo.out' }, .08);
```
> 00017 F02 · 같은 프레임에서 `#f02-ticket` 은 `y:330` 에서 올라온다 — **방향을 섞으면 화면이 산다**

- `autoAlpha` 는 `opacity` + `visibility` 다. 큐 전에 **클릭·레이아웃에서도 빠진다**
- `from` 을 주면 **등장**이다(큐 전엔 숨는다). `to` 만 주면 **상태 변화**다 (CSS 정지 상태에서 출발)

## E2. 밝기로 때린다 — 0.05초

색을 바꾸지 않고 **같은 색을 더 밝게** 한다. 팔레트를 안 건드려서 강조 예산을 안 먹는다.

```js
tl.set(NUM, { scale: 1, filter: 'brightness(1)' }, 0);
tl.to (NUM, { filter: 'brightness(1.22)', duration: .050, ease: 'power2.out' }, W.whopper);
```
> 00003 F01 훅 숫자 · **어절 온셋(`W.whopper`)에 맞춰 친다** — 소리와 같이 때려야 임팩트다

## E3. 나가는 것은 화면 밖으로

```js
tl.to('#f02-compare-one', { y: -420, autoAlpha: 0, duration: .38, ease: 'expo.out' }, 2.60);
```
> 00017 F02 · 비교가 끝난 카드를 **위로 빼낸다**
> 🔴 `dim`(제자리에서 흐려지기)으로 퇴장을 때우지 마라. 00013 실측 `dim` 18회 · `out` 0회 —
> 화면이 「지워지는」 것처럼 보였다. 나가는 건 **나가야** 한다

## E4. 방향이 있는 이동

```js
tl.fromTo('#f02-ci', { y: -90 }, { y: 0, duration: .36, ease: 'expo.out' }, 0);
```
> 00017 F02 · 위에서 내려오는 `#f02-ci`(y −90)와 아래에서 올라오는 `#f02-ticket`(y 330)이 **같은 프레임에 섞인다**

⚠️ 거리에 목표 숫자는 없다 (2026-09-16 해제). 다만 **화면 밖에서 들어오는 것**이 한 프레임에 하나는 있어야
등장이 보인다 — 20px 움직임은 사람 눈에 「떨림」이지 「이동」이 아니다.
