# resources/motion/ — 모션 재료 라이브러리

**금지 목록 대신 주는 것.** 여기 있는 건 전부 **승인본에서 실제로 돌아간 마크업**이다. 지어낸 게 하나도 없다.

```
easy.md           한 속성으로 끝나는 것 — 등장·강조·퇴장
intermediate.md   상자 안에서 값이 변하는 것 — 막대·판·카드·숫자
advanced.md       무대가 반응하는 것 — 선 그리기·연속 상태·뜯기·도장
```

## 왜 만들었나 (2026-09-16 사용자 지시)

> *"제약이 너무 많다. 클로드한테 시켜도 코덱스한테 시켜도 결과물도 실수도 똑같다."*

맞는 지적이었고, 실측이 뒷받침했다:

|---|---|
| 가이드에 쌓인 것 | 26개 문서 13,218줄 · **금지 표현 633개 · 🔴 505개** |

스레드의 [heedam_i](https://www.threads.com/@heedam_i) 가 같은 문제를 반대로 풀었다 —
모션을 **Easy / Intermediate / Advanced 로 나눠 레고처럼 쌓고**, 템플릿을 **결합**해 완성한다.
*"기획·소스·편집본이 계속 라이브러리에 쌓인다."* 우리는 같은 「라이브러리」에 **금지**를 쌓고 있었다.

## 쓰는 법

1. 컷의 문장이 **무슨 일을 하는지** 먼저 적는다 — 비교·증감·분해·경로·반전·경고
2. 주연 소재가 실제로 하는 동작을 먼저 찾고, 여기서 맞는 물리를 고르거나 새로 만든다. 서로 다른 조각의 결합은 정보 변화가 더 분명해질 때 쓴다
3. 마크업은 의도·동작 단계·읽을 결과를 확인한 뒤 해당 프레임에 맞게 바꿔 쓴다. 내부 path를 움직일 소재는 외부 파일 참조 대신 인라인으로 둔다 (`docs/02-pitfalls.md` §106). 예시의 크기·속도·이징을 기본값으로 고정하지 않는다
4. 새 동작은 실제 영상에서 발화 동기·seek 재현성·휴대폰 크기 결과를 검증하고 출처 프레임을 적을 수 있을 때만 여기에 넣는다. 아직 시험하지 않은 외부 카드는 라이브러리에 복제하지 않는다

🔴 **목표 수치는 주지 않는다.** 「이동 300~600px」·「어휘 6종」 같은 숫자는 2026-09-16 에 전부 내렸다 —
사람이 화면을 보고 내린 판정을 숫자로 바꿔 입력으로 되먹인 것이었고, 90%를 맞추고도 화면이 죽었다.
`motion-vocab` 은 계속 재지만 **막지 않는다.** 재료를 보고 고르는 게 수치를 맞추는 것보다 낫다.
