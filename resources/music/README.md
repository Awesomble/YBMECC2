# resources/music/

배경음악 라이브러리. 출처·라이선스·LUFS·**정서**는 `CREDITS.md`. 쓰는 절차(고르기 → 하이라이트 자르기 → `audio_meta.json` 기록)의 정본은 `docs/14-hyperframes.md` §5다 — 여기서 되풀이하지 않는다.

| 폴더 | 라이선스 | 용도 |
|---|---|---|
| `cc0/` | CC0(퍼블릭 도메인) — 크레딧 불필요 | 🔴 **여기서만 고른다** |
| `cc-by/` | CC BY 4.0 — 저작자 표시 의무 | 🔴 **2026-10-02부터 쓰지 않는다**(저작자 표시 소재 금지 · 화면·문안에 출처를 쓰지 않는다 — video SKILL 「에셋 제작 경로」). 파일과 `CREDITS.md` 표는 기록용 |

## 🔴 자유롭게 쓸 수 있는 곡만 쓴다 — 코드가 막는다 (2026-09-16 사용자 지시)

> *"라이센스 필수 확인후 자유롭게 활용가능한 배경음악만 사용하라고"*

`node pipeline/stage-gate.mjs <p> 4`가 `audio_meta.json.bgm.license`가 CC0·퍼블릭 도메인이 아니면 하드 실패한다. **「무료」와 「자유롭게 사용 가능」은 다르다** — 크레딧 의무가 있으면 이 저장소 기준으로는 자유롭지 않다.

## 고르기 — 이 편의 정서로 매번 (2026-09-15 사용자 지시)

> *"매번 똑같은 배경음악 사용하지 말고 컨텐츠와 분위기에 맞는 음악을 매번 찾고, 그중 하이라이트만."*

1. ②에서 README 「디자인 방향」의 **BGM 정서** 줄(차분·사색 / 애잔·향수 / 긴장·미스터리 / 진지·중립 / 따뜻·향수·포근 / 경쾌 / 활기·행진 / 으스스)을 이 편의 대본·주제로 정하고, ④에서 `CREDITS.md` 「정서」 열이 같은 곡을 고른다. **밝은 곡을 기본값으로 깔지 않는다** — 2026-10-21 감사: 132편이 업비트 4곡을 순환했고 템플스테이·달고나 긴장 훅·실종 경보에 휘파람·뉴스 징글이 깔렸다.
2. 2026-10-21 반입으로 차분·사색 / 애잔·향수 / 긴장·미스터리 / 진지·중립 / 따뜻·포근·축제 칸에 각 2곡이 있다(cc0 19곡 — YBMECC 는 2026-10-20 반입한 따뜻·포근(감동) 2곡이 더 있다). 그래도 맞는 곡이 없으면 **새로 받는다**(아래) — 「맞는 곡이 없어서 경쾌한 곡」은 선택 이유가 아니다. 남은 후보는 `CREDITS.md` 「반입 후보」.
3. 직전 편들과 같은 곡이면 다른 구간과 이유를 적는다(`stage-gate 4`가 직전 5편과 대조해 경고한다). 시작초·대역 처리(carve)는 **곡마다 잰다** — 앞 편 값을 복사하지 않는다.
4. `audio_meta.json.bgm`에 title·composer·source·license·`mood`·`why`를 적는다(형식·조립·레벨은 docs/14 §5).

### 새 곡 받을 때 — 라이선스를 먼저 확인한다

| 출처 | 라이선스 | 확인법 |
|---|---|---|
| **FreePD**(2025년 폐쇄) | CC0 | 웨이백 분류 페이지(`web.archive.org/web/<스냅샷>/https://www.freepd.com/<분류>.php`)의 「Free Of Attribution, Creative Commons 0」·곡별 「Written by <작곡>」 원문과 원 mp3 주소 — 검증 사슬은 `CREDITS.md` 「출처 검증 기록」 |
| **OpenGameArt** | 곡 페이지 「License(s)」 필드가 **CC0**인 것만 | 페이지 원문·확인일을 적는다. 올린 이와 작곡자가 다르면 작곡자 쪽 출처를 근거로 |
| **ccMixter** `lic=zero` | CC0 | 곡 페이지의 라이선스 표기 |
| ❌ Pixabay·Mixkit(자체 Content License — CC0가 아니다) · Incompetech 직접(CC BY) · 작곡자 Anonymous · 「CC0」를 스스로만 주장하는 팩 | — | 쓰지 않는다 |

받은 파일은 SHA-256과 페이지 원문을 `legal/<날짜>/`에 보존하고, `ffmpeg -af ebur128`로 LUFS를 재서 `CREDITS.md` 표에 정서 열까지 한 줄 더한다. Content ID 오청구 이력이 있는 작곡가(Rafael Krux)보다 화이트리스트가 확인된 쪽(Kevin MacLeod)을 같은 칸에서 먼저 고른다. 다운로드는 사용자가 허락한 범위에서만 한다.
